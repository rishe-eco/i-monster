# imnstr

The code for IMNSTR.com, a bilingual personal site (English, and Persian right to left under `/fa/`): a public log and podcast page, and a private admin for one author. It is a single Node process with server-rendered pages and a SQLite file, and it sets no cookies on public pages.

The plan, the spec and the design are in the `root-sot` repository, under `imnstr/modules/01-website/`. House rules and commands for working in this repo are in [`CLAUDE.md`](CLAUDE.md); the stage list is in [`docs/development/README.md`](docs/development/README.md).
