## Decided

The lane's calls (report item 4), each accepted at review:

- **No `republish` route.** `publish` covers it; the date is kept by `COALESCE`, and the answer carries `firstPublishedAt` for AC-34's notice.
- **An existing `publishKey`** answers 200 with the same bytes as a new row and writes nothing, not even `last_language`. The key is lowercased.
- **`PUT` reads only the title and body;** `lang`, `state`, dates and `publishKey` are ignored. `NOT_FOUND` comes before the body.
- **S-11:** signed in, an unknown `/admin/api` path, or a known path with a wrong method, is JSON `NOT_FOUND` 404; signed out, 401. An unknown `auth/*` path stays the public HTML 404. An unknown list cursor is `NOT_FOUND`.
- **`STATUS` and `refuse` stay in `routes/admin-api.ts`** (`admin-copy.test.ts` parses that table); the entry router takes `{refuse, readJson}`. B7 does the same.
- **`last_language`** is written on a save, a created row and a publish that changed state; not on an unpublish or a refused save.
- **The generic `NOT_FOUND` message** ("That isn't there any more.") now serves passkeys and entries.
- **The lane's copy** (plate 8 gives none): the empty state, the three refusals, "Opening…". The founder may change it; nothing depends on the wording but the e2e tests.
- **Publish uses `btn--primary btn--solid`** (ink fill, plate 8); the list reloads when the frame changes an entry and when the section opens.
