## Built

- **Body schema.** `shared/doc.ts`: `doc > paragraph+ > text+`, marks `link{href}` (https, http, mailto) and `highlight`, nothing else (PD-7). `validateDoc` returns a clean copy or `{ ok: false }`; `docHasText` for B5; `docFromText` reads the textarea-fallback markup (`[text](url)`, `==text==`) for seeds and tests. It imports nothing, so B5–B6's admin bundle can share it.
- **Render.** `lib/render.ts`: `<p>`, `<a rel="noopener">` for web links (none for `mailto:`), `<mark>`. Every text node goes through `lib/bidi.ts`, which escapes it. `lib/escape.ts` is the one HTML/XML escape.
- **Bidi.** `lib/bidi.ts`, `isolate(text, lang)` and `isolateRuns`. URLs become `<bdi dir="ltr">` without their trailing punctuation. In Persian, Latin runs become `<bdi lang="en">`. In English, Arabic-script runs become `<bdi lang="fa" dir="rtl">`, drawn in `--font-read-fa`. The landing page's who paragraph, project names and project lines go through it (S-2), and `latinName` is gone from `SiteContent`.
- **Entries, read side.** `lib/entries.ts`: `getPublished`, and `listPublished` ordered `first_published_at DESC, id ASC` with an explicit keyset cursor, reading one row past the page. `insertPublished` is the one insert, shared by the seed CLI and the e2e routes.
- **Feed.** `lib/feed.ts`, Atom per language, by hand with no XML dependency: `xml:lang`, self and alternate links, the 20 newest, full content as `type="html"` (Persian inside `<div dir="rtl">`), untitled titles as the date in full (`formatFeedTitleDate`, new in `lib/dates.ts`), dates as PD-24.
- **Routes and pages.** `routes/log.tsx`, mounted by one line in `app.ts`: `/log`, `/log/<id>`, `/log/feed.xml`, and the same under `/fa/`. Views `views/log.tsx` (entries, "Older entries", the empty state) and `views/entry.tsx` (no previous or next; a visually hidden `<h1>` with the date when untitled). `views/fill.tsx` fills `{placeholders}` in locale strings with elements. CSS for both pages in `components.css`.
- **Seeding.** `scripts/seed-entry.ts` (`npm run seed-entry -- --lang en|fa [--title …] --body-file …`, database from `DB_PATH`), and the test-only `POST`/`DELETE /__test/entries` in `routes/test.ts`, mounted only with `E2E_CLOCK=1`.
- **Tests.** Unit `doc`, `bidi`, `render`; integration `log`, `feed`, `entries`; e2e `log.spec.ts` and `entry.spec.ts`, both languages and both schemes, at 360 and 180 px.

**The review changed** (`a4f4df4`, and `CLAUDE.md` with this record):
- **`C++`, `C#` and `.NET` in Persian were split.** The Latin run stopped before `+`, `#` and a leading `.`, so `C++` was isolated as `C` and drawn `++C` right to left. A run now keeps a trailing `+`/`#` and a leading dot before a letter. Measured in the browser: every character of the three names in order, left to right.
- **One control character broke the whole feed.** The schema accepts any text, and XML 1.0 forbids most of C0. Word's line break, U+000B, pasted into an entry, would have made both feeds malformed for every reader. `escapeHtml` now drops those characters (and U+FFFE/U+FFFF) everywhere; they draw nothing on a page either.
- **The owner's name** on the entry page and the 404 was a hand-written `<bdi lang="en">`. It now goes through `isolate()` (house rule 4): isolated in Persian, plain in English.
- **`CLAUDE.md`** says to install with `--ignore-scripts`, and why (below).
- Three new tests, each confirmed failing on the lane's code and passing after the fix.

## Decided

The lane's calls (report item 4), each accepted at review:

- **`paragraph+ > text+`:** a paragraph must hold a non-empty text node. ProseMirror stores an empty paragraph with no `content`, so **B5/B6 must drop empty paragraphs before saving** or loosen the schema (owed).
- **Order `first_published_at DESC, id ASC`,** with `(t < ct) OR (t = ct AND id > cid)`. Tested across a same-millisecond page boundary.
- **A cursor** must be a published entry of the same language; anything else gives that language's 404. "Older entries" links `?before=<last id shown>`.
- **The bidi rules** as built (above). Isolation is per text node, so a run crossing a mark boundary is isolated in two parts. Accepted: the parts keep their order.
- **An empty feed's `<updated>` is `now()`,** since Atom requires one. Cost, accepted: an empty feed's ETag changes on every request, so it never answers 304. It is a few hundred bytes, and only until a language has its first entry.
- **`formatFeedTitleDate`:** "13 October 2026", "۲۸ مهر ۱۴۰۵", without the time `formatEntryDate` carries.
- **The untitled entry page's hidden `<h1>`** holds the same date string as the feed title.
- **`POST /__test/entries`** takes a batch and answers `{ids}`; `ENTRY_INVALID` is a test-only code, outside §6.2.
- **The seed CLI** prints the entry's path and exits 1 with a usage line on bad arguments. Tried by hand: four entries seeded; `--lang de` refused.
- **`latinName` removed;** `isolate` finds Latin runs itself. `pages.test.ts` still asserts `<bdi lang="en">Root</bdi>` on `/fa/`.
- **`--font-read-fa`** for Persian runs in English text.
- **The empty state has no eyes;** they are B9's.

**Where the plan, card or brief was wrong** (report item 5, answered):

The package ships `prebuilds/win32-x64.node` (and Linux ones) and loads it at run time, so `--ignore-scripts` loses nothing. `CLAUDE.md` is fixed here. **Still wrong:** `brief-common.md`, and `config.md` §6, whose milestone script runs a bare `npm ci`. B2's image will meet the same `node-gyp` call (owed).

3. **The 404's owner line** wasn't routed through `lib/bidi.ts`: fixed at review.
4. **Plan §5 B3 and §6.1** list `lib/render.ts`, `lib/feed.ts` and `lib/entries.ts` only. The stage also needed `lib/escape.ts`, `views/log.tsx`, `views/entry.tsx` and `views/fill.tsx`. Accepted.
